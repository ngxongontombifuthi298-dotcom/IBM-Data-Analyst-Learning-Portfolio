# IBM Data Analyst Capstone Project

This folder will showcase my capstone project for the IBM Data Analyst Professional Certificate upon completion, subject to the course's assessment and sharing guidelines.

The capstone is an opportunity to apply the data analytics skills developed throughout the certificate to a practical analytical problem, demonstrating the process of working with data, analysing findings and communicating results.

## Project Overview

Project details, the analytical problem and the dataset will be documented here upon completion of the capstone.

## Analytical Process

- Data collection
- Data exploration
- Data wrangling and preparation
- Data analysis
- Data visualisation
- Dashboard development, where applicable
- Findings and insights
- Recommendations
- Conclusion

## Skills Demonstrated

Python | SQL | Data Cleaning | Data Analysis | Data Visualisation | Dashboard Development | Analytical Problem-Solving

## Project Deliverables

Permitted notebooks, scripts, visualisations, reports and project documentation will be added as the capstone progresses.

**Objective:** Demonstrate the ability to apply data analytics techniques to a practical problem and communicate findings in a structured, meaningful and professional manner.
