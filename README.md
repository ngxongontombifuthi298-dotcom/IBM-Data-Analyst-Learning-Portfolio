
# IBM Data Analyst Learning Portfolio

## About This Portfolio

Welcome to my IBM Data Analyst Professional Certificate learning portfolio. This repository documents my ongoing journey towards developing practical data analytics skills through hands-on coursework, exercises and projects.

As I progress through the certificate, I am building experience in data collection, data cleaning, exploratory data analysis, SQL, Python, Excel, data visualisation and business intelligence.

My goal is to develop the technical, analytical and problem-solving skills required to transform raw data into meaningful insights that support evidence-based decision-making.

## Skills I'm Developing

- **Excel:** Data cleaning, spreadsheet analysis, formulas, pivot tables and reporting.
- **Python:** Data manipulation, exploratory data analysis and automation.
- **SQL:** Database querying, data extraction, filtering and aggregation.
- **Data Visualisation:** Charts, dashboards and communicating analytical findings.
- **Data Analytics:** Data preparation, analysis, interpretation and problem-solving.

## Portfolio Structure

### Excel Projects
Practical exercises and projects involving spreadsheet-based data cleaning, analysis, calculations, reporting and visualisation.

### Python Projects
Projects involving Python, Pandas, NumPy, data wrangling, exploratory data analysis and analytical programming.

### SQL Projects
Database analysis and querying exercises demonstrating SQL techniques used to retrieve, manipulate and analyse data.

### Data Visualisation
Charts, dashboards and visual storytelling exercises focused on presenting data clearly and communicating insights.

### Capstone
An end-to-end data analytics project demonstrating the application of skills developed throughout the IBM Data Analyst Professional Certificate, subject to course-sharing permissions.
